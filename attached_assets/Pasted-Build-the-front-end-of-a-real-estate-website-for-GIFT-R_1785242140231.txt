Build the front-end of a real estate website for GIFT Real Estate (est. 1990, Addis Ababa).

(no database, no backend, no animations yet — those come in later phases).

You have full creative freedom on UI/UX, layout, and typography — use your best design
judgment to make it look professional, modern, and trustworthy for a real estate brand.
I only care that the brand colors below are applied correctly; everything else
(fonts, spacing, exact layout) is your call.

TECH STACK
- React (Vite) + Tailwind CSS
- React Router for page navigation
- Store dummy listings as a local JS/JSON array (e.g. src/data/listings.js) with fields:
  id, title, type (sale/rent), price, location, neighborhood, bedrooms, bathrooms,
  sizeSqm, description, images[], status, dateAdded

PAGES TO BUILD (real structure, working navigation, dummy content is fine)

2. Properties/Listings page — grid of ALL dummy listings, with filter UI controls for
